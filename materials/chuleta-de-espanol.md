# La chuleta de español: 25 fórmulas para decir mucho más de lo que crees
*Shared by Eva on 2026-10-15 (photo: chuleta-de-espanol.jpg). She asked for it to be used in her lessons.*

## 1. Di más con verbos básicos
1. **Quiero + infinitivo** → Quiero viajar.
2. **Tengo que + infinitivo** → Tengo que trabajar.
3. **Voy a + infinitivo** → Voy a estudiar.
4. **Acabo de + infinitivo** → Acabo de comer.

## 2. Habla de tu pasado
5. **Solía + infinitivo** → Solía bailar.
6. **Iba a + infinitivo** → Iba a estudiar.
7. **He intentado + infinitivo** → He intentado aprender.
8. **Quería + infinitivo** → Quería viajar.

## 3. Condicional (haría / podría / debería)
9. **Me gustaría + infinitivo** → Me gustaría viajar.
10. **Podría + infinitivo** → Podría viajar.
11. **Debería + infinitivo** → Debería estudiar.
12. **Cambia la terminación → -ía** → Viajaría. / Estudiaría.

## 4. Di mucho con un solo verbo
13. **Olvidé + infinitivo** → Olvidé estudiar.
14. **Decidí + infinitivo** → Decidí viajar.
15. **Empecé a + infinitivo** → Empecé a estudiar.
16. **Dejé de + infinitivo** → Dejé de trabajar.

## 5. Suena mucho más natural
17. **Todavía + verbo** → Todavía estudio español.
18. **Ya no + verbo** → Ya no trabajo aquí.
19. **Sigo + gerundio (-ando / -iendo)** → Sigo aprendiendo.
20. **Estoy a punto de + infinitivo** → Estoy a punto de comer.

## 6. Cuando se te va la cabeza
21. **Creo que…** → Creo que sí.
22. **Para mí…** → Para mí, es difícil.
23. **La cosa es que…** → La cosa es que no sé.
24. **Depende de…** → Depende de ti.
25. **No sé, pero…** → No sé, pero creo que sí.

## 7. «Llevo tiempo haciendo…»
- **Llevo + tiempo + gerundio** → Llevo dos años nadando.

### Cómo formar el gerundio
- -AR → -ando: estudiar → estudiando, trabajar → trabajando
- -ER / -IR → -iendo: comer → comiendo, vivir → viviendo
